# DELGHE · DÈLGHEM

[![DÈLGHEM — native FEM for Apple Silicon, original Genius application screenshot](https://www.delghe.com/assets/banners/delghem-billboard-en.webp)](https://www.delghe.com/)

**DÈLGHEM** is an independent structural engineering software project **in development for macOS on Apple Silicon**. The project focuses on original native 3D modelling, FEM workflows, source-backed numerical benchmarks, structural drawings and the **Genius Assistant** for engineer-reviewed text commands.

**[Official website](https://www.delghe.com/)** · **[Sito italiano](https://www.delghe.com/it/)** · **[Genius demonstration](https://www.delghe.com/en/genius-fem-assistant-mac/)** · **[Official banner & press kit](https://www.delghe.com/en/media-kit/#promotional-banners)**

### Engineering examples / Esempi tecnici

- [**Pile foundations, Winkler grade beams and layered soil**](https://www.delghe.com/en/pile-winkler-foundations-mac/) — actual DÈLGHEM D2 t-z/q-z axial pile results. The soil stress-spreading overlay is an explicitly approximate analytical visualization, *not a geotechnical continuum FEM check*.
- [**Viscous dampers: compare two steel-frame responses**](https://www.delghe.com/en/viscous-dampers-steel-fem-mac/) — two synchronized numerical equivalent SDOF Newmark histories of a native D2 planar S355 steel portal, with and without equivalent viscous damping.
- [**Genius FEM Assistant**](https://www.delghe.com/en/genius-fem-assistant-mac/) — authentic D2 Mac application screenshots and controlled examples of structural model commands.

**Release and scientific scope:** A vAlpha1 release is *planned* for 2027. The application is not advertised here as a finished or certified engineering product. Benchmark claims apply only to their respective published example models and analytical assumptions; they are not general building-safety or seismic certifications.
